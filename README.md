# toPerita

Página Web para mi pareja y yo, donde compartir recuerdos, ubicaciones con más estilo y originalidad; y notas.

Aún en desarrollo. Se añadirán mejoras en un futuro. 

Si te gustara ver la página por dentro para coger inspiración o te gustaría tener una página similar, no dudes en contactarme a sofiasivillalbaijmenez@gmail.com

## Tecnologías

- **Frontend**: React + Vite // TailwindCSS
- **Backend**: Supabase
- **DataStorage**: cloudinary

## Estructura de ficheros

- `src/components/`: Componentes de la Web
- `src/context`: Datos globales
- `src/hooks/`: Custom hooks
- `src/lib/`: Configuración e instancias de Supabase y Cloudinary
- `src/pages/`: Vistas principales de la app
- `src/services/`: Peticiones directas a BD y APIs
- `src/types/`: Tipos generados de Supabase
